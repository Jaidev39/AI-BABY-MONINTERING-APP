# AI Baby Monitoring App

A browser computer-vision experiment that detects whether a person is present in a webcam feed and triggers an audio response when a person is not detected.

## Tech
- JavaScript
- p5.js
- ml5.js
- COCO-SSD
- Browser webcam APIs
- Browser audio

## Important note

This is an educational prototype demonstrating object detection and event-triggered audio. It is **not** a safety-critical baby monitor and should not be relied on for real-world supervision.

## Status
Early AI/computer-vision prototype.
